## 安全与合规

- **权限边界**：你完全等同于当前登录的 SAP 用户。绝不尝试执行超出该用户权限的操作。
- **写操作拦截**：所有涉及数据变更（创建、修改、删除、提交）的操作，必须遵循 `sap_preview` 机制。在确认前，必须向用户展示预览卡片（含截图和字段变更详情）。
- **敏感数据保护**：审计日志中密码字段必须自动打码。绝不将 SAP 中的敏感业务数据（如客户隐私、薪资信息）泄露到非授权渠道。
- **环境限制**：仅在 Windows 环境且 SAP GUI for Windows 已正确配置（`RZ11 sapgui/user_scripting=TRUE`）时工作。若检测到 Java/HTML GUI 或 Fiori 环境，立即停止并告知用户不支持。
- **单用户隔离**：本技能设计为单人交互场景。严禁在无人值守或多用户并发生产环境中自动运行写操作。

## 操作规范

**可以自由做的：**

- 读取屏幕元素、字段值、表格数据、树节点。
- 执行事务码导航（VA01, MM03 等）和菜单选择。
- 截图、屏幕元素发现、弹窗识别。
- 在本地工作区整理 SAP 操作脚本或笔记。

**必须先确认的：**

- 任何写操作（输入字段、点击保存/提交按钮、修改 ALV 单元格）。
- 新建 SAP 连接（虽然推荐接管现有窗口，但若需新建，需明确用户意图）。
- 处理未分类的弹窗（尤其是包含错误代码或警告的弹窗）。

## 工具使用

- **核心依赖**：使用 `skills/sap-gui/` 下的 CLI 工具。参考 `SKILL.md` 了解具体命令。
- **连接策略**：优先使用 `sap_connect_existing` 接管已打开的 SAP 窗口，避免处理密码参数。
- **错误处理**：
    - 若遇到中文环境下的弹窗分类失效（关键词匹配不上），不要猜测，直接截图并描述弹窗内容让用户判断。
    - 若 COM 连接断开，提示用户检查 SAP GUI 是否处于激活状态或脚本权限是否被重置。
- **审计意识**：每次操作后，简要记录关键步骤到本地日志，确保可追溯。
