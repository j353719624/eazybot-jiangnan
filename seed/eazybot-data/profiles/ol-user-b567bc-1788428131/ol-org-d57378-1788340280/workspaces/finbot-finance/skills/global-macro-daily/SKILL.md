# 全球宏观策略日报

## 概览

生成一份覆盖全球主要市场的宏观策略日报 Markdown + HTML 文件。**日报定位为盘后晚报**，复盘当日 A 股/港股/日韩收盘 + 隔夜美股。

**核心原则：**
- 数据说话，观点克制，不预测方向，不推荐买卖
- 策略建议必须基于当日机构观点的共识方向综合，每条标注依据
- **每个数据点必须双源校验后写入，单源数据不写进报告**
- **所有数据源在报告中统一标注 "Gangtise、公开数据整理"，禁止出现终端名**
- 美股取「最近一个美股交易日」收盘，通过 exchange-calendars 实时查询，不写死 T-1
- **日报正文禁止出现**：数据校验过程、数据源名称、数据缺失/超时说明、任何内部流程描述

### 数据源总则

| 数据类别 | 主力源 | 校验源 |
|----------|--------|--------|
| A 股指数 | Gangtise Data（quote.py） | GT KB 当日市场日报交叉验证 |
| 港股指数 | Gangtise Data（quote.py） | GT KB 当日市场日报交叉验证 |
| 美股指数 | 新浪 API（hq.sinajs.cn）gb_ixic/gb_dji/gb_spx | GT KB + 财联社新闻，三源验证 |
| 日韩指数 | 财联社每日收盘数据 | Wind 新闻交叉验证 |
| 利率/汇率/美元指数 | Gangtise EDB（industry_indicator.py） | 央行官网、中国货币网(chinamoney.com.cn)、中央结算公司、中债估值 |
| 大宗商品 | 新浪期货连续合约（hf_CL / hf_GC）+ 财联社隔夜全球要闻 | 双源交叉比对（偏差 <0.5% 取均值，>0.5% 取第三源） |
| 资金流向 / 成交额 | Gangtise Data（fund_flow.py）主力 | 财联社盯盘页面校验 |
| 机构观点 | Gangtise File（report.py / opinion.py / foreign_report.py） | Gangtise KB 交叉验真 |
| 核心主题 | Gangtise KB + Agent | web_search / 财联社双源确认 |
| 宏观日历 | GT KB 研报日历 | 财联社 / 金十数据（jin10.com）二次校验 |

## 工作流

按顺序执行以下步骤，每步完成后再进入下一步。

### 第 0 步：交易日确认

必须用 `exchange-calendars` 确认各市场状态：

```bash
cd <exchange-calendars-skill-dir>
python3 scripts/trading_calendar.py is_open A股
python3 scripts/trading_calendar.py is_open 港股
python3 scripts/trading_calendar.py is_open 美股
```

- A 股 / 港股：取上一个交易日收盘（通常 T-1，跨周末/假期自动回退）
- 美股：取最近一个美股交易日收盘（用 is_open 逐日回退确认）。周一取上周五，周二取周一
- 日股 / 韩股：同样取最近交易日

在日报开头注明各市场复盘日期。

### 第 1 步：拉取数据

按以下顺序并发拉取所有数据，不做串行等待。

#### 1.1 指数行情（Gangtise Data 主力）

⚠️ A 股/港股/美股全部走 Gangtise Data 的 `quote.py`。日韩走财联社 + Wind 新闻双源。

**A 股指数**（全部合并查询）：

```bash
cd <gangtise-data-skill-dir>
python3 scripts/quote.py --securities 上证指数,沪深300,科创50,上证50,创业板指,深证成指,中证500 -sd yyyy-MM-dd -ed yyyy-MM-dd
```

**港股指数**：

```bash
python3 scripts/quote.py --securities 恒生指数,恒生中国企业指数,恒生科技 -sd yyyy-MM-dd -ed yyyy-MM-dd
```

**美股指数**（取最近美股交易日，三源验证）：

主力源——新浪 API：

```bash
# 美股三大指数
curl -s 'https://hq.sinajs.cn/list=gb_ixic,gb_dji,gb_spx' -H 'Referer: https://finance.sina.com.cn'
```

解析方式：
- `gb_ixic` → 纳斯达克综合指数（第2字段=收盘价，第3字段=涨跌幅%）
- `gb_dji` → 道琼斯工业指数（同上）
- `gb_spx` → 标普500指数

校验——GT KB + 财联社新闻：

```bash
python3 scripts/kb.py -q "道琼斯 标普500 纳斯达克 收盘 美股" -sd <今天> -ed <今天> -l 3 --file-types "外资研报,研究报告"
web_search site:cls.cn 隔夜全球要闻 美股
```

> 三源验证：新浪API数值为主力，GT KB和财联社新闻方向性校验（点位±0.5%、涨跌幅符号一致）。数值冲突时取三源中值。

**日韩指数**（财联社每日收盘 + Wind 新闻交叉验证）：

```bash
# 财联社搜索日韩收盘
web_search 日经225 7月X日收盘价 / Korea KOSPI 收盘
# Wind 新闻交叉验证（搜索当日全球市场行情综述）
```

> 指标名称可用中文简称，`quote.py` 自动解析。日韩指数 Gangtise 不覆盖（KRW/JPY计价不支持），故用财联社收盘数据主力 + Wind 新闻交叉验证。

#### 1.2 利率 + 汇率（Gangtise EDB 主力）

⚠️ **分两批拉取**，一次太多指标会截断返回。

**第一批**（美债 + 中债 1Y/5Y）：

```bash
cd <gangtise-data-skill-dir>
python3 scripts/industry_indicator.py --indicators M00003643,M00003647,M00003649,M00000257,M00000259 \
  -sd yyyy-MM-dd -ed yyyy-MM-dd
```

**第二批**（中债10Y/30Y + 汇率）：

```bash
python3 scripts/industry_indicator.py --indicators M00009661,M00002075,M00000493,M00000661 \
  -sd yyyy-MM-dd -ed yyyy-MM-dd
```

> 日期范围取最近 5 天，确保覆盖所有市场最近交易日。周末/假期无数据为 NaN。

**交叉验证源**（写入前至少选 1 个核验）：
- 中国货币网：`chinamoney.com.cn` → 查询 DR 系列、Shibor、回购利率
- 中央结算公司 / 中债估值：查询中债收益率曲线
- 央行官网（pboc.gov.cn）：查询政策利率、公开市场操作
- 用 `web_search` 打开上述网站核验债券利率数据

> 债券类数据上报前必须用以上公开源交叉核验，确保收益率走势和绝对数值无误。

#### 1.3 大宗商品（新浪期货连续合约 + 财联社隔夜全球要闻双源确认）

⚠️ 不走 Wind EDB，也不走 Gangtise EDB（延迟严重）。所有品种使用**期货连续合约**收盘价。

**主力源 — 新浪期货连续合约：**

```bash
# WTI原油期货连续（CL.NYM 即 NYMEX WTI 连续）
curl -s 'https://hq.sinajs.cn/list=hf_CL' -H 'Referer: https://finance.sina.com.cn'

# COMEX黄金期货连续（GC.CMX 即 COMEX 黄金连续）
curl -s 'https://hq.sinajs.cn/list=hf_GC' -H 'Referer: https://finance.sina.com.cn'
```

新浪期货连续合约返回格式（GBK编码）：
- `hf_CL` → WTI 原油连续 | 字段：名称, 昨收, 开盘, 最高, 最低, 最新价...
- `hf_GC` → COMEX 黄金连续 | 同上

**校验源 — 财联社隔夜全球要闻：**

```bash
# 搜索财联社隔夜全球要闻，提取 WTI/黄金/白银/LME铜 收盘价
web_search site:cls.cn 隔夜全球要闻 WTI 黄金 白银 LME
```

**LME 数据：** 从 Gangtise KB 研报中的有色金属基差日报获取（如 LME 铜 3M 收盘价）。

**数据提取规则：** 新浪期货连续合约数值为主力，财联社新闻方向性校验。双源偏差 <0.5% 取均值，>0.5% 取第三源确认。

> 大宗商品只用 WTI 原油连续、COMEX 黄金连续、COMEX 白银连续、LME 铜 3M 四个品种。一律标注为期货连续合约收盘价。不写国内商品期货。

#### 1.4 A 股资金流向 + 成交额（Gangtise 主力 + 财联社校验）

**Gangtise** — 全市场资金流向 + 成交额汇总：

```bash
cd <gangtise-data-skill-dir>
python3 scripts/fund_flow.py --all-market -sd yyyy-MM-dd -ed yyyy-MM-dd --limit 8000
```

运行后对 CSV 全量求和得到总净流入、主力净流入（大单+特大单）。

**财联社盯盘页面校验** — 成交额：

```bash
# 打开财联社盯盘页，读取两市成交额及较上日变化
open https://www.cls.cn/finance
# 页面中可见：两市成交额 X.XX万亿，较上日 +/-XXXX亿
```

> 成交额以 fund_flow.py 全市场成交额加总为主力，财联社页面数值校验方向。两值偏差 >5% 时取中值。

#### 1.5 热点主题 + 机构观点（Gangtise 双源验证）

⚠️ **机构观点必须当天（≤1天），国内 5 条 + 海外 5 条，各侧均覆盖 4 维度（宏观、贵金属、策略、赛道）**。每条 100-200 字。禁止全部集中在单一维度。

**核心主题双源验证规则**：
- 从 Gangtise KB 或 Agent 获取的主题/事件描述 → **必须用 web_search 财联社或同类信源二次确认后方可写入**
- 禁止单源直接写入核心主题（仅凭 GT KB 或仅凭 GT Agent 都不行）
- 双源确认项包括：事件真实性、数据准确性、时间正确性

**热点话题**：

```bash
cd <gangtise-agent-skill-dir>
python3 scripts/hot_topic.py -sd yyyy-MM-dd -ed yyyy-MM-dd --hot-category morning,evening --with-securities --page-size 100
```

**国内机构观点**（Gangtise File 主力，4 轮搜索覆盖宏观/贵金属/策略/赛道）：

```bash
cd <gangtise-file-skill-dir>

# 贵金属

# 策略

# 赛道

```

**海外机构观点**（Gangtise File 外资研报，同样 4 轮）：

```bash
cd <gangtise-file-skill-dir>

# 宏观
python3 scripts/foreign_report.py -k "Fed rate inflation Powell monetary policy" -sd <今天> -ed <今天> -l 10

# 贵金属
python3 scripts/foreign_report.py -k "gold silver precious metals commodity" -sd <今天> -ed <今天> -l 10

# 策略
python3 scripts/foreign_report.py -k "US equity SP500 Nasdaq sector strategy outlook" -sd <今天> -ed <今天> -l 10

python3 scripts/foreign_report.py -k "AI semiconductor tech industry Nvidia" -sd <今天> -ed <今天> -l 10
```

> 任一维度不足时用 `web_search` 财联社/华尔街见闻补充当天最新观点。每个维度在国内外两侧各至少 1 条，剩余 1 条自由分配到覆盖最弱的维度。

#### 1.6 交叉验证（web_search）

用财联社、新浪财经等公开源对以下数据进行快速校验：
- 各指数收盘点位与涨跌幅
- 利率和汇率数据（确保无跳变）
- 机构观点的时效性和准确性

#### 1.7 宏观日历（GT KB 主力，财联社/金十校验）

**规则：**
- **只列未来 2 周以内的事件**，不列太远的日期
- **GT KB 为主力源**：从研报中的日历/大事前瞻表格提取事件
- **财联社/金十数据为校验源**：用 `web_search` 财联社或金十数据（rili.jin10.com）确认日期
- 注意时区转换：FOMC 决策日（美东周三 2pm）= 北京时间周四凌晨

> 禁止凭记忆写日期。禁止含前值列。禁止显示超过2周后的事件。

### 第 2 步：编写日报

#### 日报 Markdown 模板

日报分为两部分输出：

1. **Markdown 文件**：纯文本格式化，面向快速阅读和存档
2. **HTML 文件**：卡片式设计，参考 Gangtise 模板风格

## 日报结构规范

### 七段式结构

| 段 | 标题 | 内容 |
|----|------|------|
| 一 | 市场总体复盘 | A股全部指数 + 港股 + 日经 + 韩国 + 美股三大指数，合并显示 |
| 二 | 利率与汇率 | 美债 2Y/10Y/30Y、中债 1Y/5Y/10Y/30Y、中美利差、美元/人民币、美元指数 |
| 三 | 大宗商品 | 贵金属 + LME 6 品种 + WTI 原油 |
| 四 | 今日核心主题 | 梳理当日行情重点和重要数据/事件，4 个主题卡片 |
| 五 | 机构观点精选 | **国内 5 条 + 海外 5 条，各侧均覆盖 4 维度（宏观、贵金属、策略、赛道）**。每条用 `[维度] 报告原文标题（日期）` 格式，正文 100-200 字。末尾总结「观点共识与分歧」。禁止出现机构名称和分析师名称。禁止单维度集中。 |
| 六 | 策略建议 | ✅ 相对看好 / ⚠️ 需谨慎。**必须基于当日机构观点的共识方向综合归纳，不得凭空判断。** 每项建议标注对应数据或观点依据。 |
| 七 | 关键事件日历 | 站在今天视角，仅列未来有明确事件安排的日期；无事件则不展示该日期行 |
| — | 风险提示 | 当前主要风险 |
| — | Footer | `数据来源 Gangtise & Wind · 仅供参考，不构成投资建议`<br>`以上内容基于FinBot制作` |

### HTML 设计规范

- 指数数据：卡片式布局（grid），每个指数独立卡片，标红涨绿跌
- 利率/汇率/大宗：卡片式 macro-grid，大字号数值
- 核心主题：4 个带标签卡片（🔥最热 / 📌关键 / 🆕新叙事）
- 机构观点：分为"国内机构观点"和"海外机构观点"两节，各 5 条；末尾加"观点共识与分歧"总结框
- 策略建议：左右双栏（✅相对看好 / ⚠️需谨慎）
- 事件日历：仅显示今日起未来日期，不列已发生事件
- 风险提示：红底风险框
- Footer：两行，第二行 `以上内容基于FinBot制作`
- **禁止出现**：数据校验过程描述、数据源说明、内部流程暴露

### 宏观日历校验规则

**宏观日历每一条目必须经过 GT KB + web_search 双重校验后才能写入报告。**

执行顺序：
1. **GT KB 搜索**：用 `gangtise-kb` 搜索当日/当周研究报告中的宏观日历（如华福证券周报、西部证券宏观日历、JPM FTM日历等）
2. **web_search 交叉验证**：搜索金十数据、财联社、新浪财经等公开日历页面，确认日期和事件名称一致
3. **时区转换**：美联储 FOMC 等美国事件用 US 日期（决策日通常是周三美东），写进报告时转换为 **北京时间**（FOMC 公告北京时间通常是周四凌晨）

**禁止事项：**
- 禁止凭记忆、推测或之前日报中的旧日期写入
- 禁止只查单源即写入（必须 ≥2 源确认）
- 禁止在日历中包含已发生的事件（只列未来事件）
- 禁止在日历中包含"前值"列

**认可的数据源：**
- 首选：GT KB 研究报告中的日历表格（华福证券、西部证券等）
- 次选：JPM FTM、摩根士丹利 Global Macro Outlook 等外资研报中的日历
- 校验：web_search 财联社、金十数据、新浪财经等公开页面

## 校验规则

日报中每个数据点必须满足以下校验：

| 数据类别 | 主力源 | 校验源 | 校验方式 |
|----------|--------|--------|----------|
| A股指数 | Gangtise Data（quote.py） | GT KB 当日市场日报 | 点位 ±0.5%、涨跌幅符号一致 |
| 港股指数 | Gangtise Data（quote.py） | GT KB 当日市场日报 | 点位 ±0.5%、涨跌幅符号一致 |
| 美股指数 | 新浪 API（gb_ixic/gb_dji/gb_spx） | GT KB + 财联社新闻 | 三源验证：点位 ±0.5%、符号一致，冲突取中值 |
| 日韩指数 | 财联社每日收盘 | Wind 新闻 | 点位 ±1%、涨跌幅符号一致 |
| 美债/中债收益率 | Gangtise EDB | 央行官网/中国货币网/中债估值 | 绝对偏差 < 5bp |
| 汇率/美元指数 | Gangtise EDB | 中国货币网（chinamoney.com.cn） | 小数点后 3 位一致 |
| 大宗商品（WTI连续/黄金连续/白银连续/LME铜3M） | 新浪期货连续合约 + 财联社隔夜全球要闻 | 双源交叉比对 | 偏差 < 0.5% 取均值，>0.5% 取第三源 |
| A股资金流向 / 成交额 | Gangtise fund_flow 主力 | 财联社盯盘页面 | 方向一致，成交额偏差 <5% |
| 机构观点 | Gangtise File（report.py / opinion.py / foreign_report.py） | Gangtise KB 交叉验真 | 确认来源存在、时效 ≤7 天 |
| 核心主题 | Gangtise KB + Agent | web_search 财联社 | 双源确认事件真实性和数据准确性 |
| 宏观日历 | GT KB 研报日历 | 财联社 / 金十数据 | 只列未来 2 周内事件，双源确认日期 |

校验不通过的数据点，优先用校验源数值替换，并在日志中标记。
