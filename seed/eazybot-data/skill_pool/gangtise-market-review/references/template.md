# A股市场全景复盘 — 报告模板 

本文件提供市场全景复盘报告的 Markdown 结构模板。撰写报告时以此为骨架，填入当日实际数据。

---

### 本期概要

> 市场判断：...(一句话核心判断，50字内)
> 关键变化：...(指数/板块/资金的当日关键变化)
> 数据覆盖：Gangtise 热点话题 X 条 | 指数行情 | 核心标的 N 只 | 题材指数 X 个 | 机构观点 X 条 | 投研线索 X 条

## 04 热点拆解

### 热点判断方法

使用以下数据源综合判断当日热点：
1. `gangtise-agent/scripts/hot_topic.py` — 全天热点话题（按热度/出现频次排序）
2. `gangtise-data/scripts/concept.py` — 题材指数（投资逻辑 + 成分股）
3. `gangtise-agent/scripts/security_clue.py` — 投研线索（按证券/行业筛选当日线索）

### 热点组织原则

根据当日热点话题的自然结构来组织：
- 如果某天只有1个极强热点占主导，详细拆解这1个
- 如果某天有2-3个热点并行，分别拆解
- 如果某天热点分散，按热度排序，重点拆解前2-3个

每个热点包含：
- **催化来源**（来自 hot_topic / security_clue 的具体事件）
- **核心数据**（来自 quote / concept / industry_indicator）
- **产业链传导**（上游→中游→下游，各环节标的表现和逻辑）
- **相关标的当日表现**

### 热点一：名称

**催化来源：**
- 具体催化事件（映射到热点话题或投研线索）
- 数据支撑

- 数据点 1
- 数据点 2

| :--- | :------- | :----: | :--- | :------: |

## 05 机构声音

### 获取方法（从 file）

使用 `gangtise-file` 检索当日/近期机构观点：

```bash
# 首席观点
python3 scripts/opinion.py -k "[热点关键词]" -sd YYYY-MM-DD -ed YYYY-MM-DD -l 20

# 研究报告
python3 scripts/report.py -k "[热点关键词]" -sd YYYY-MM-DD -ed YYYY-MM-DD -l 20

# 会议纪要
python3 scripts/summary.py -k "[热点关键词]" -sd YYYY-MM-DD -ed YYYY-MM-DD -l 20
```

> 所有机构观点从 `gangtise-file` 获取。`gangtise-kb` 不在本工作流中使用。

### 观点整理

精选 5-8 条与当日热点相关的机构观点，每条包含：
- 来源（机构名称 / 报告类型）
- 核心结论（1-2句话）
- 与当日行情的关联

> 筛选与主线高度相关的观点，无关观点省略。标注机构名称。
