# 市场全景复盘 · 写作质量标准

## 数据要求

| 项目       | 要求                                                      |
| :--------- | :-------------------------------------------------------- |
| 数据来源   | 基于 Gangtise API 拉取的真实数据                          |
| 指数覆盖   | 含上证/深证/创业板/科创50/北证50/上证50/沪深300/中证500   |
| 标的覆盖   | 至少覆盖成交额TOP10 + 涨跌幅TOP10（各10只以上），跨板块   |
| 热点覆盖   | 全天热点话题（早报/午报/盘中/晚报）≥20条                  |
| 题材覆盖   | 当日热点相关的题材指数投资逻辑 + 成分股                   |
| 机构观点   | 精选 5-8 条与当日热点相关的机构观点（研报/首席观点）      |
| 投研线索   | 核心标的的当日投研线索                                    |
| 产业链拆解 | 每个热点拆解到"环节"层面                                  |
| 风险矩阵   | 含风险类别/描述/指标/状态/临界值/应对                     |
| 明日推演   | 2-3个情景，以"若..."条件句触发（如"若无重大变量""若催化发酵""若外部扰动"），不标注概率数字   |

## 排版规范

1. **标题分层**：核心判断标题（headline）超过 30 字时，拆分为三层：主标题（1行核心判断）+ 副标题（1-2行行情说明）+ 催化剂标签卡片（横向排列的多个关键词标签，浅色背景分隔）。标签卡片 CSS：`background: var(--paper-deep); border: 1px solid var(--border); padding: 4px 12px; border-radius: 4px; font-size: 12px`。
2. **标的格式**：所有表格中列出的标的统一使用"名称（代码）"格式（如"博瑞医药（688166）"），名称和代码同时出现。
3. **涨跌颜色**：所有涨跌幅数值使用预定义 CSS 类 `.up`（红涨）和 `.down`（绿跌），不使用内联 style 或自定义类名，确保全报告颜色统一。

## 写作原则

1. **先有核心判断，再展开细节**：开篇 50 字内说清当日市场，读者读完能清晰转述
2. **数据驱动**：每个数字有出处，罗列有意义的数据
3. **读者视角**：假设读者是机构投资者，5 分钟能读完并形成判断
4. **归因链完整**：每板块的个股涨跌，映射到 Gangtise 热点话题/投研线索/首席观点里的具体催化事件
5. **产业链思维**：分析个股涨跌的同时，拆解"上游-中游-下游"各环节的逻辑传导
6. **主线稀缺**：主线数量根据当日热点自然结构决定，通常不超过 3 条
7. **情景推演**：明日推演给出 2-3 个情景，以"若..."条件句触发（如"若无重大变量，市场大概率延续...""若催化进一步发酵，市场有望...""若外部出现扰动，市场可能..."），不标注具体概率数字，但给出指数区间和板块判断
8. **首席观点精选**：筛选与主线相关的观点，无关观点省略

## 风格

- 暖纸底色文学风 / 高端投研风
- 克制、数据优先、逻辑清晰
- 用词平实（避免"暴涨""井喷""王者归来"等营销话术）
- 用事实和数字表达观点，感叹号仅在封面/关键判断处使用
- 产业链拆解用"环节→标的→逻辑→弹性"四列

## HTML 呈现规范

1. **涨跌颜色**：涨用红色 `var(--up)`，跌用绿色 `var(--down)`。所有涨跌幅数据统一使用 `.up` / `.down` 或 `.chg-up` / `.chg-down` 类名
2. **标的展示**：所有表格中的股票统一使用"名称（代码）"格式，名称和代码同时出现
3. **标题层级**：使用 headline（核心判断一句话）+ headline-sub（80-120字描述）+ catalyst-tags（3个核心催化标签卡片）三层结构，标签用 `.catalyst-tag.accent` 标记前两个最重要催化

## 质量检查清单

生成报告前，逐项确认：

- [ ] 数据均来自 Gangtise API
- [ ] 指数覆盖 ≥ 8 个
- [ ] 核心标的覆盖 ≥ 20 只（含TOP10成交 + TOP10涨跌）
- [ ] 热点话题覆盖全天（早报+午报+盘中+晚报）
- [ ] 热点按自然结构组织，每个有产业链拆解
- [ ] 机构观点 ≥ 5 条且与热点相关
- [ ] 风险矩阵 ≥ 5 个风险类别
- [ ] 明日推演有 2-3 个情景，定性判断，不标注概率数字
- [ ] 所有标的均使用"名称（代码）"格式
- [ ] 涨跌幅颜色统一使用 `.up`/`.down` 类名，无内联样式
- [ ] 标题分层清晰（主标题+副标题+催化剂标签）
- [ ] HTML 使用新版模板（暖纸底色 Parchment Ledger）
