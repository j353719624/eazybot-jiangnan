# 研报图片调用指导

## 简介

按关键词搜索研报中的图片，返回图片元数据（标题、描述、来源、页码等）及 `chunkId`（可用于下载原图）。主脚本：`scripts/report_image.py`。

检索接口**无积分消耗**；下载原图按 **0.1 积分/张** 计费。

## 主脚本：执行检索

| 参数 | 必填 | 说明 |
|------|------|------|
| `-k` / `--keyword` | 是 | 搜索关键词，如 `AI`、`新能源汽车`。 |
| `-sd` / `--start-date` | 否 | 开始时间，如 `2024-01-01` 或 `2024-01-01 00:00:00`。 |
| `-ed` / `--end-date` | 否 | 结束时间，如 `2024-12-31` 或 `2024-12-31 23:59:59`。 |
| `-l` / `--limit` | 否 | 返回数量上限，默认 10，最大 20。 |
| `--source-id` | 否 | 研报 ID，限定特定研报来源（可从研报列表或知识库获取）。 |
| `-d` / `--download` | 否 | 是否在检索后自动下载图片原文件，默认不下载。 |
| `-od` / `--output-dir` | 否 | 下载图片保存目录，建议使用绝对路径。默认保存在 gangtise 工作目录下的 `report_image` 目录。 |

**无枚举值接口的参数**（如 `keyword`、时间范围等）：直接传入用户意图相关文本即可。

## 调用示例

**按关键词搜索：**
```bash
python3 scripts/report_image.py -k AI -l 10
```

**按关键词 + 时间范围：**
```bash
python3 scripts/report_image.py -k 新能源汽车 -sd 2024-01-01 -ed 2024-12-31 -l 5
```

**限定特定研报：**
```bash
python3 scripts/report_image.py -k 算力 --source-id 297236012319510528
```

**检索并自动下载图片：**
```bash
python3 scripts/report_image.py -k AI -sd 2024-01-01 -ed 2024-12-31 -d true
```

## 返回说明

- **成功**：返回图片列表，每条包含研报标题、发布时间、券商、页码、图注、页面内容描述，以及 `file-type：研报图片`、`file-id：<chunkId>`。
- **下载**：使用返回的 `chunkId` 作为 `file-id`；检索时加 `-d true` 可自动下载原图。
- **失败**：返回错误信息；关键词为空、无匹配结果或接口异常时会提示具体原因。
