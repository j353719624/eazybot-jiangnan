# 排错

## 空集：先不要下「没有符合条件的股票」的结论

按顺序排查：

1. **报告期不对**（最常见）。报表类指标的 `reportDate` 未落在报告期末，或落在季报上而条件是年度口径
   （「ROE>15%」在一季报上必然筛出空集）。先把 reportDate 换成最近年报重试
2. **占位值 `0`**。EDE 取不到数时多数指标返回 `null`（比较运算会跳过），但个别指标返回 `0`
   ——最常见的是 `is_dnrpnp`（扣非归母净利润）。`0` 会照常参与比较，`F1 > 0` 因此必然空集。
   用独立技能 `gangtise-data` 的 `company_indicator.py --securities <代表证券> --indicators <指标编码>`
   单查该指标，确认拿到的是真值还是占位值（非本技能依赖）
3. **量纲搞错**。传了 `scale=8`（亿）后表达式阈值也要用「亿」（500 亿写 `> 500`）；
   不传 scale 时总市值单位是元（500 亿要写 `> 50000000000`）。两边单位不一致要么全命中、要么全不命中
4. **条件过严**。逐条放宽重试，定位是哪一条杀光了结果
5. 以上都排除后，才是「确实没有标的满足」

## 常见错误码

| 码 | 含义 | 处理 |
| :-- | :-- | :-- |
| `100003` | 指标编码 / 证券代码 / 参数名有误，msg 会点名是哪个 | 按 msg 修改。美股后缀是 `.O` / `.N`，不是 `.US` |
| `100001` | 缺必填参数，msg 带参数名 | 在对应 `indicatorList[].parameters` 里补上。同时要 `tradeDate` 和 `reportDate` 的指标必须两个都给 |
| `140002` | 终态参数错：必填参数缺失、枚举越界、表达式语法错 | **不重试**，读 `parameterList` 后修改参数 |
| `110003` | 超出账号数据权限的时间范围 | 把日期移进范围。撞界时先用 `company_indicator.py` 单查同一天验证，能取到就改用它拉数再本地筛 |
| `130001` | 数据未找到，或该指标无权限 | 换证券 / 日期仍失败多为无权限，联系客户经理开通 |
| `999999` | 系统故障（无数据已不再使用此码） | 参数无误仍报即服务端问题，不要重试 |

## 指标在该范围内无数据列

服务端报 `binding mismatch` 或某变量 `has no column` 时，不是参数错，而是某个指标
在这个选股范围内一列数都没有，表达式因此无法求值。最常见的原因是**该范围内的公司
不披露这个科目**——例如银行没有营业成本，因而没有销售毛利率；保险没有存货周转率。

处理：定位到出问题的那个指标，换一个适用于该范围的口径，或更换选股范围。
不要把原始的 `binding mismatch` 报错甩给用户。

## 退出码与失败形态

| 形态 | 含义 |
| :-- | :-- |
| `exit_code=0` 且有 `rows` | 正常（含「零命中」这种正常空集，此时 `total: 0`） |
| `blocked: true` + 退出码 1 | payload 本地校验未通过（缺字段 / field 格式错 / expression 引用未定义变量 / 参数不成对），**未发起计费请求**，按 blockers 修好后重跑 |
| `exit_code: 1` + `error`/`traceId` | 服务端业务失败或网络失败。Markdown / `--json` 都会带上接口返回的 `msg`（以及 `errorType`/`code`/`traceId`），不要只看 HTTP 状态行 |

`resolve-indicator` 返回 `status: search_error` 时是接口 / 鉴权问题（如 token 过期、限流），
不是「指标不存在」——先修鉴权再重试，不要据此下结论。

参数名不要带展示用的必填标记：`-p` 里写 `periodNum`，不要写成 `periodNum*`
（解析表里的「（必填）」只是说明，不是键名的一部分；脚本也会自动剥掉尾部 `*`）。
## 模型需自行校验的点（脚本不拦）

- **同一指标同参数不能绑两个 field**：服务端会报「重复配置」。同一指标不同参数
  （如两个日期的收盘价）可以各绑一个变量做跨期比较
- **指标的 `markets` 与选股范围的市场要匹配**：构造 payload 前对照 `resolve-indicator`
  返回的 `markets` 与 universe 所属市场（A股 / 港股 / 美股），不匹配时该列取不到数、
  整条表达式无法求值，先换指标或换范围
- **两融 `mgn_*` 的 tradeDate 要回退一个交易日**：当天入库为 null，用上一交易日

## 其它约束

- `screener` 只过滤不排序。TopN 需先用条件筛出候选，再取回数据本地排序
- 表达式只支持「变量 比较 常量」，不支持 `F1/F2` 这类跨指标运算
- `contains` / `notcontains` 仅对 `dataType: string` 的指标有效，且大小写不敏感
