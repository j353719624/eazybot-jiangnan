# 选股范围（universe）

payload 的 `universe` 同时接受 **10 位板块 ID**、**证券代码**，多个取并集。
板块 ID 必须来自本技能搜索结果（`screener.py resolve-universe` 或 `run -u` 自动解析），
不能凭空构造。

推荐直接用自动串联，不必手查 ID：

```bash
python3 scripts/screener.py resolve-universe "白酒板块"
python3 scripts/screener.py run -u "白酒板块" -i "ROE" -e "F1 > 15"
```

## 行业板块：默认走中信

同一个行业名在多个体系里都有（中信 / 申万 / 恒生 / 概念），搜索会一起返回。
**默认取「中国内地股票-中信行业类」**；用户点名「申万 / 概念 / 题材 / 恒生」才切换
（对照剥壳输出的 `system` 提示与候选的 `hierarchy`）。中信一级行业 ID 示例：
银行 `1000000316`、半导体 `1000000366`、白酒 `1000000287`、医药 `1000000272`、
汽车 `1000000198`、食品饮料 `1000000285`、电子 `1000000365`、计算机 `1000000399`、
房地产 `1000000334`、煤炭 `1000000023`、有色金属 `1000000031`、国防军工 `1000000190`、
电力设备及新能源 `1000000173`。

行业简称需先翻译再检索：酿酒→白酒、芯片→半导体、有色→有色金属、军工→国防军工、
地产→房地产、券商→证券、化工→基础化工、新能源→电力设备及新能源。

## 🔴 指数成分股：平台不支持

`沪深300 / 中证500 / 中证1000 / 上证50 / 科创50 / 创业板指 / 北证50 / 恒生指数 /
标普500 / 纳斯达克100` **都拿不到成分股**：

- 板块搜索查不到沪深300（「指数数据板块」里装的是指数**本身**，不是成分股）
- screener 的 universe 传指数代码（如 `000300.SH`）报 `100003 不是有效证券或者板块ID`

需如实告知用户，并给出替代路径（按优先级）：

1. **用户自己有成分股名单** → 直接把代码列表塞进 `universe`（`-u 600519.SH,000858.SZ`）
2. **用户有导出的成分股文件（csv 等）** → 读出代码列塞进 `universe`
3. **用近似范围 + 规模条件** → 如「沪深A股 + 总市值 ≥ 300 亿」近似沪深300。
   ⚠️ 这只是近似，**必须在回复里说明这不是真正的指数成分股**
4. 均不可行时说明当前无法满足，不要静默换成别的板块

「创业板指 / 科创50 / 北证50」要和「创业板 / 科创板 / 北证A股」区分开：后者是可用的
市场类板块，前者是指数。用户说「创业板」用 `1000000007`，说「创业板指成分股」才走上面的降级。

## 板块查不到时

1. 先剥壳：`python3 scripts/universe_strip.py "机械范围"` → `机械`、`"银行业"` → `银行`
2. 再换同义词：按剥壳输出里的 `rewrite` 改写词重搜（`酿酒` → `白酒`）
3. 还不行 → 可能是个股名，`resolve-universe` 会自动回退证券搜索；也可 `-u 600519.SH`
4. 仍不行 → 让用户确认，或改用 `scr_concept contains '<题材>'` 当**条件**、范围放宽到全部A股
