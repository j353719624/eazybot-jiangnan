# 指标解析：口径、参数、量纲

## 解析链路

`resolve-indicator <说法>`（以及 `run -i` 内部）分四步：

1. **抽口径** —— 剥出「单季 / TTM / 累计 / 同比 / 环比 / N期均值 / 预测 / 周月季年区间」，
   剩下的是裸名。报告期词（年报 / 中报 / 季报…）会先被摘掉，不会污染裸名
2. **多路检索** —— 裸名 → 原文 → 大写形态 → 改写表目标 → 去掉修饰前后缀
   （公司/静态/综合…、规模/水平/占比/倍数/估值…）→ 中心词；主关键词全部弱命中时才启用退化词
3. **本地重排** —— 文本相似度 + 接口相关性分数 + 口径一致性 + 限定词一致性
   + 比率/存量语义 + 现金流量表重名科目降权
4. **判定 status** —— `ok` / `ambiguous`（前两名分差 < 8）/ `weak` / `not_found` /
   `unavailable`（平台没有，直接给替代口径）/ `search_error`（接口或鉴权失败，修鉴权重试）

`run -i` 要求每个指标 `status=ok`，否则 blocked 返回候选、不计费。

`resolve-indicator` 的 Markdown 输出对齐 `company_indicator`：每条候选含适用范围、算法说明，
以及参数明细表（参数编码 / 名称 / 类型 / 必填 / 默认值 / 说明 / 枚举）。`-p` 键填「参数编码」。

两条影响使用方式的接口特性：

- **对英文缩写大小写敏感**：`PE` 的匹配强度显著高于 `pe`，脚本已自动补齐大写形态
- **相关性分数区分度很高**：命中容错名时为几千到上万，无关结果只有十几到一百多。
  因此 `not_found` 基本等于「平台确实没有这个指标」，而不是「没搜对」

## 口径消歧

同一个中文说法常对应多个编码，差异都在口径维度：

| 维度 | 取值 | 用户未点名时的默认 |
| :-- | :-- | :-- |
| 报表期间 | 累计 / 单季度 / TTM / TTM(报告期) | **累计** |
| 资产负债 | 期末 | **期末** |
| 行情周期 | 日 / 周 / 月 / 季 / 半年 / 年 / 区间 | **日** |
| N 期统计 | 原值 / N期均值 / N期最小值 / N期最大值 | **原值** |
| 增长 | 原值 / 同比 / 环比 | **原值** |
| 预测 | 已实现 / 预测 | **已实现** |

最终回复要写清用的是哪个（例：「营业收入(利润表,累计)，报告期 2025-12-31」）。
`status: ambiguous` 时列出候选让用户选，不要代为拍板。

**限定词改一个就是换科目**，不能丢：归母 / 扣非 / 每股 / 少数股东 / 基本 / 稀释 / 自由流通。

## 日期与必填参数（`run -i` 自动补全）

按指标 `params` / `required` 路由（可用 `--trade-date` / `--report-date` / `-p` 覆盖）：

| parameterList | 自动行为 |
| :-- | :-- |
| 有 `tradeDate` | 填最近交易日（脚本查日 K）；`mgn_*` 填上一交易日 |
| 有 `reportDate` | 填最近已披露年报期末 |
| 两者都必填（如 `div_cash_yld`） | 两个都填 |
| 无任何日期参数（`pty_*` / `scr_*` / `div_cash_yr`…） | 不传 tradeDate |
| `scale` | 仅当 `-p` 提供时写入 |

其它高频必填参数（缺失报 `140002`）：

| 参数 | 适用 | 说明 |
| :-- | :-- | :-- |
| `periodNum` | N 期统计类 | 无默认值，须 `-p` 给出 |
| `sDate` | 区间类的起始日 | 参数名就是 `sDate`，写成 `startDate` 会报错 |
| `fiscalYear` | 年度分红、预测类 | 预测类取当年，已实现类取最近已披露年份 |
| `industryType` + `industryLevel` | `scr_indu` | 两个都必填 |

**报告期默认取最近已披露年报，不是最近一期。** 比率与增速类条件按季度口径会得到
反直觉的结果——「市值>500亿 且 ROE>15%」在白酒板块落到一季报上命中 0 只、
落到上一年年报上命中 3 只。

**两融数据 T+1 入库**：`mgn_*` 的 tradeDate 由脚本自动用上一交易日。

## 量纲

`scale` 是指标的参数：`0`元 / `3`千 / `4`万 / `6`百万 / `8`亿 / `9`十亿 / `12`万亿。
**传了 scale 后指标值和表达式阈值都用对应量纲**——scale=8（亿）时「市值超 500 亿」
写 `"F2 > 500"`；不传 scale 时总市值单位是元（万亿级公司约 1.6e12）。
比率/百分比类指标不要加 scale；`倍` `%` `元` `天` 不是量纲，不要映射成 scale。
跨市场比较市值前统一 `currency` 参数（如 `DFT`）。

## 平台未提供的指标（`status: unavailable`）

流通市值 / 自由流通市值、Beta、波动率、夏普、股东户数、机构持股比例、北向（陆股通）持股、
净负债率、估值历史分位、涨跌停标记、龙虎榜、限售解禁、员工人数。

遇到时说明不支持并给替代口径，不要用相近指标顶替：

- 流通市值 → 只有总市值 `qte_mkt_cptl`；自由流通市值需 `shr_free × 收盘价` 自行计算
  （screener 表达式不支持跨指标运算）
- 波动率 → 用区间振幅 `qte_amp_intvl` 近似
- 估值历史分位 / 股东户数等单证券分析 → 使用独立的 `gangtise-data` 技能（非本技能依赖）

## 文本型指标（支持 contains / notcontains）

`pty_op_scope` 经营范围、`pty_main_bus` 主营业务、`pty_prfl` 公司简介、
`scr_concept` 证券所属概念、`scr_indu` 所属行业、`scr_exchg_sctr` 上市板块、
`scr_abbr` 证券简称、`mgn_flag` 是否融资融券标的（取值「是」/「否」）。

`scr_concept` 可用于板块查不到题材时的兜底：范围放宽到全部A股，
再用 `"F1 contains '<题材>'"` 作为条件。
